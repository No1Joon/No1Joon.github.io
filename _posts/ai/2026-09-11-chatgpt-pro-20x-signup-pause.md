OpenAI가 가장 비싼 등급의 판매를 멈췄습니다. 월 29만 9,000원(200달러)짜리 ChatGPT Pro 20x의 신규 가입과 업그레이드가 2026년 9월 10일부터 막혔어요.

이유는 장애가 아니라 수요입니다. 일주일 전 공개한 GPT-6 Astra를 감당하려고 시스템 부하가 가장 큰 등급의 유입을 끊었습니다.

이미 쓰고 있는 사람은 그대로 쓸 수 있습니다. 다만 한 번 구독이 끝나면 재개될 때까지 다시 살 수 없어요.

![OpenAI 워드마크](/assets/images/ai/chatgpt-pro-20x-signup-pause/01-hero-openai-logo.webp)
*OpenAI 워드마크 — 출처: OpenAI*

## 무슨 일이 있었나

OpenAI는 2026년 9월 10일(현지 시간) ChatGPT Pro 20x 등급의 신규 가입을 중단했습니다. 제품·플랫폼 총괄인 Thibault Sottiaux가 X에 올린 글로 알렸고, TechCrunch와 국내 매체들이 같은 날 이를 전했어요.

- 막힌 대상은 **Pro 20x(월 29만 9,000원)** 하나입니다
- 신규 가입뿐 아니라 **하위 등급에서 올라오는 업그레이드**도 함께 막혔습니다
- 기존 구독은 영향을 받지 않고 계속 갱신됩니다
- 재개 시점은 공지되지 않았습니다

Sottiaux는 이 등급이 시스템에 가장 큰 부하를 준다고 밝혔고, 가능한 한 빨리 컴퓨트 용량을 늘리고 있다고 덧붙였습니다.

> 현재 이용자들이 최고 경험을 누리고 Astra를 계속 이용할 수 있도록 월 200달러 Pro 요금제의 신규 가입을 일시 중단합니다

가장 작은 조치로 최대한 넓은 접근을 유지하려 했다는 설명도 같은 글에 있습니다. 전체 서비스의 속도를 낮추거나 Plus 한도를 깎는 대신, 한 등급의 유입만 끊는 쪽을 골랐다는 뜻이에요.

## 어디까지 멈췄나

멈춘 것은 판매뿐입니다. 서비스 자체가 닫힌 것이 아니어서 Astra를 쓰는 경로는 대부분 그대로 열려 있어요.

| 요금제 | 신규 가입 | 비고 |
| :--- | :--- | :--- |
| Go | 가능 | 가장 낮은 유료 등급 |
| Plus | 가능 | Work·Codex에서 Astra |
| Pro 5x | 가능 | **Plus의 5배 사용량** |
| Pro 20x | <mark>중단</mark> | 업그레이드도 막힘 |
| Business | 가능 | 좌석 단위 계약 |
| Enterprise | 가능 | 좌석 단위 계약 |
| API | 가능 | 종량제 |

Free·Go·Plus·Pro 5x 어디에서 올라오려 해도 20x 등급으로는 갈 수 없습니다. 요금을 낼 의사와 무관하게 경로 자체가 닫혀 있어요.

![구독 등급이 한 방향으로만 움직이는 상태](/assets/images/ai/chatgpt-pro-20x-signup-pause/02-agy.webp)

## 기존 Pro 20x 가입자가 지금 조심할 것

이번 조치에서 실질적인 손해가 생기는 자리는 기존 가입자 쪽입니다. 구독을 유지하는 동안은 아무 일도 없지만, 끊기는 순간 되돌릴 방법이 없어요.

- 해지나 다운그레이드를 **예약**하면 청구 주기가 끝날 때까지는 20x를 그대로 씁니다
- 주기가 끝나기 전이라면 결제 설정에서 그 예약을 **취소할 수 있습니다**
- 주기가 끝나 구독이 종료되면 재개 전까지 재구매가 막힙니다
- 환불·결제 실패·프로모션 종료로 구독이 끝나도 결과는 같습니다

환불이 구독을 취소시키는 형태라면 접근이 즉시 끊기고 계정은 Free로 내려갑니다. 한 달만 쉬었다가 다시 올라오는 선택은 재개 공지가 나오기 전까지 성립하지 않아요.

그래서 유지 여부는 취향이 아니라 금액으로 따질 문제가 됩니다. OpenAI는 한국에 원화 정가를 따로 두고 있어 Pro 20x가 월 29만 9,000원, Pro 5x가 15만 9,000원입니다. 둘 다 부가세가 포함된 금액이고 원화로 청구돼 카드 해외결제 수수료가 붙지 않아요.

![ChatGPT 유료 요금제 한국 월 구독료](/assets/images/ai/chatgpt-pro-20x-signup-pause/03-chart.webp)
*ChatGPT 유료 요금제 한국 월 구독료 — 출처: OpenAI 한국 요금표 기반 자가 렌더*

한 등급 내려가면 매달 **14만 원**이 남습니다. 다만 그 선택이 확정되는 순간 재개 공지가 나올 때까지 20x로 돌아올 길이 막히고, 아끼는 금액은 그 자격과 맞바꾸는 값이 됩니다.

## Pro 20x는 누구에게 필요한 등급이었나

Pro는 월 15만 9,000원(5x)과 29만 9,000원(20x) 두 갈래로 나뉘고, 숫자는 Plus 대비 사용량 배수를 가리킵니다. 이번에 막힌 쪽은 배수가 가장 큰 등급이에요.

OpenAI가 Codex 요금표에 올린 5시간 기준 로컬 메시지 추정 구간을 보면 등급 차이가 드러납니다. Plus가 5~45건, Pro 5x가 25~225건, Pro 20x가 100~900건입니다.

![요금제별 5시간 메시지 상한, Sol과 Astra](/assets/images/ai/chatgpt-pro-20x-signup-pause/04-chart.webp)
*요금제별 5시간 메시지 상한, Sol과 Astra — 출처: OpenAI Codex 요금표 기반 자가 렌더*

같은 요금제에서 Astra는 GPT-5.6 Sol의 절반쯤 되는 메시지 수를 줍니다. 모델 한 번 호출에 드는 자원이 그만큼 크다는 뜻이고, 20x 등급이 시스템에 가장 큰 부하를 준다는 설명과도 맞물려요.

채팅 화면에서 쓰는 GPT-6 Pro는 주간 단위로 따로 걸립니다.

| 요금제 | 주간 GPT-6 Pro |
| :--- | :--- |
| Plus | 포함 안 됨 |
| Pro 5x | 50건 |
| Pro 20x | **200건** |

다만 OpenAI는 요금제별 주간 메시지 상한을 숫자로 공개하지 않습니다. 요금표가 제시한 추정 구간은 작업 길이와 도구 호출 횟수에 따라 실제 체감이 달라질 수 있어요.

정리하면 20x는 Codex 에이전트를 하루 내내 돌리거나 긴 문서를 반복해 처리하는 사용 패턴을 위한 등급입니다. 대화와 검색이 주된 용도라면 5x에서 한도를 다 쓰기도 쉽지 않습니다.

## 지금 새로 가입하려면

20x 등급이 막혔을 뿐 Astra를 쓰는 경로는 넷이 남아 있습니다.

| 경로 | 성격 |
| :--- | :--- |
| Pro 5x | **구매 가능한 최고 한도** |
| Plus | Astra는 Work·Codex에서만 |
| Business | 좌석 단위, 관리자 설정 필요 |
| API 종량제 | 쓴 만큼만, 요금제와 무관 |

![GPT-6 Astra API 100만 토큰 단가](/assets/images/ai/chatgpt-pro-20x-signup-pause/05-chart-api.webp)
*GPT-6 Astra API 100만 토큰 단가 — 출처: OpenAI API 요금표 기반 자가 렌더*

원화 정가는 Pro 5x가 월 15만 9,000원, Plus가 2만 9,000원입니다. 20x에서 5x로 내려가면 매달 14만 원, Plus까지 내려가면 27만 원이 남습니다.

API는 요금제와 무관하게 열려 있어 한도 자체가 없습니다. 입력 100만 토큰에 1만 3,400원(10달러), 출력 100만 토큰에 6만 7,000원(50달러)이고, Batch와 Flex는 절반, Fast 모드는 두 배예요. 입력이 27만 2,000 토큰을 넘으면 그 요청만 입력 두 배·출력 1.5배로 올라갑니다.

20x 한 달 값인 29만 9,000원을 출력 토큰에만 쓰면 약 440만 개가 나옵니다. 사용량이 들쭉날쭉한 개인에게는 종량제가 더 맞을 수 있고, 매일 한도를 끝까지 쓰는 사람에게는 구독이 쌉니다.

구독료는 국내 카드와 카카오페이·네이버페이로 원화 결제되고, 환율이 움직여도 매달 같은 금액이 빠집니다. 달러로 과금되는 쪽은 API 하나뿐이에요.

## 2023년에도 같은 일이 있었습니다

OpenAI가 수요를 이유로 판매를 멈춘 것은 처음이 아닙니다. 2023년 11월 첫 DevDay 직후 ChatGPT Plus 신규 가입을 중단했고, Sam Altman은 수요가 회사의 컴퓨트 용량을 넘었다고 설명했습니다.

![OpenAI가 수요를 이유로 신규 가입을 막은 기록](/assets/images/ai/chatgpt-pro-20x-signup-pause/06-chart.webp)
*OpenAI가 수요를 이유로 신규 가입을 막은 기록 — 출처: OpenAI 공식 발표·외신 보도 기반 자가 렌더*

그때는 약 한 달 뒤 재개됐습니다. 이번에는 전체 유료 등급이 아니라 최상위 하나만 막았다는 점이 다르고, 그만큼 조치의 폭도 좁아요.

새 모델이 나오면 가장 비싼 등급으로 수요가 몰리고, 그 등급이 인프라를 가장 많이 쓰는 탓에 판매가 먼저 멈춥니다. 모델 공개와 판매 중단 사이의 간격은 이번에 일주일이었습니다.

## 앞으로 주목할 점

- **재개 공지가 어디로 나오는지** 봐야 합니다. 이번 중단도 요금제 페이지가 아니라 담당자의 X 글로 먼저 알려졌습니다
- **Pro 5x와 Plus의 한도가 조정되는지**가 다음 신호입니다. 20x 수요가 아래 등급으로 몰리면 그쪽 부하가 올라갑니다
- **Astra의 속도·가격 등급이 갈리는지** 지켜볼 만합니다. 이미 API에는 Batch·Flex·Fast로 속도와 가격을 나눈 선택지가 있습니다
- **경쟁사 최상위 등급의 반사 수요**도 변수입니다. Claude Max와 Google AI Ultra도 최상위 등급을 같은 가격대에 두고 있어 비교 대상이 뚜렷해요

Pro 20x를 쓰고 있다면 이번 달 결제 설정을 열어 예약된 해지나 다운그레이드가 없는지 확인하고, 새로 가입하려던 분이라면 Pro 5x로 갈지 API로 갈지를 사용량 기준으로 따져 보는 것이 먼저입니다.
