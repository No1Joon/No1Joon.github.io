KT가 10월 7일 생활 서비스형 AI **「모두의 AI」**를 공개하고 10월 클로즈 베타, 12월 정식 출시 일정을 밝혔어요. 업스테이지·모티프·NC AI·솔트룩스의 국산 모델과 리벨리온의 국산 AI 반도체를 한 서비스에 통합한 구성입니다.

과학기술정보통신부가 8월 28일 선정한 정부 사업 「모두의 AI」의 KT 컨소시엄 결과물이에요. KT는 질문 응답과 쇼핑·예약·조회 같은 실제 서비스 이용을 연결하겠다고 설명했습니다.

![KT 로고](/assets/images/ai/kt-moduui-ai/01-hero-kt-logo.webp)
*KT 로고*

## 사건 경과

정부는 6개 컨소시엄이 지원한 「모두의 AI」 프로젝트에서 SK텔레콤·카카오·KT 세 곳을 8월 28일 최종 선정했어요. 선정 사업자에는 올해 NVIDIA B200 GPU 512장을 지원하고, 2027년부터 정부 예산으로 전 국민 서비스 운영비를 지원합니다.

- 8월 18일: 과기정통부, 참여 신청 6개 컨소시엄 공개
- 8월 28일: SK텔레콤·카카오·KT 컨소시엄 최종 선정
- 9월: 협약 체결과 실무협의체 구성
- 10월 7일: KT, 모두의 AI 공개와 클로즈 베타 시작
- 12월: 정식 서비스 출시 예정

## 모델 역할 분담

![업스테이지 로고](/assets/images/ai/kt-moduui-ai/02-logo-upstage.webp)
*업스테이지 로고*

KT는 다섯 개 국산 AI 모델을 작업에 따라 구분해 사용합니다. 사용자의 질문이 들어오면 KT의 **토큰 팩토리** 기술이 질문의 난도와 성격을 분석해 적합한 모델에 요청을 전달하는 구조예요.

| 참여사 | 맡는 일 |
| :--- | :--- |
| 업스테이지 | <mark>Solar 모델</mark>, 범용 대화·장문 분석 |
| 모티프 | 긴 문맥·대규모 문서 분석 |
| NC AI | 3D 콘텐츠·음성·사운드 생성 |
| 솔트룩스 | 컨소시엄 모델 참여 |
| 다음 | 검색 서비스 연계 |
| 리벨리온 | **국산 NPU 클러스터** |

KT 차경훈 팀장은 이렇게 모델을 나눠 쓰는 방식으로 비용과 연산 효율이 약 16~20% 개선됐다고 설명했어요. 솔트룩스가 어떤 기능을 맡는지는 공개된 보도에 구체적으로 나오지 않았습니다.

## 서비스가 하는 일

KT는 이 방식을 **이음 인사이드**라고 불러요. 모두의 AI 앱을 따로 여는 대신, 이미 쓰는 서비스 안에 AI 버튼을 추가해 해당 서비스에서 질문하고 기능을 실행하게 한다는 전략입니다.

| 연계 서비스 | 공개된 예시 |
| :--- | :--- |
| 무신사 | 결혼식 복장 추천부터 구매까지 |
| 마이KT | 월 요금·데이터 사용량 조회 |
| 지니 TV | 정확한 제목 없이 콘텐츠 검색 |
| 다나와 | 상품 페이지에서 추가 질문 |
| 부동산 | 예산·통근 조건 맞춘 매물과 시세 |

정부 사업 선정 때 KT 컨소시엄에는 다음·무신사·직방·EBS·BC카드가 연계 서비스로 참여했어요. 10월 클로즈 베타는 날씨·주식·콘텐츠 같은 정보 질문의 정확도와 안정성을 먼저 확인하고, 예약·신청처럼 실행까지 하는 기능은 12월 정식 출시 때 확대할 계획입니다. 내년 상반기에는 파트너 계정을 연동해 한 번 로그인으로 연결된 서비스를 쓰게 할 예정이에요.

## 국산 NPU 인프라

![리벨리온 로고](/assets/images/ai/kt-moduui-ai/03-logo-rebellions.webp)
*리벨리온 로고*

추론 인프라는 리벨리온의 국산 AI 반도체로 구성한 NPU(신경망 처리 장치) 클러스터예요. 정부가 지원하는 B200 GPU와 함께, 국산 칩이 전 국민 대상 서비스의 실제 트래픽을 처리하는 사례가 됩니다.

KT 관계자는 사용 이력 정보나 맥락을 잘못 이해해 생기는 문제를 개선하고 있고, 보안 거버넌스를 과기정통부와 협의하고 있다고 밝혔어요. 어떤 개인정보가 어느 참여사 모델로 전달되는지는 아직 공개되지 않았습니다.

## 정부 사업 구도

![SK텔레콤 로고](/assets/images/ai/kt-moduui-ai/04-logo-sktelecom.webp)
*SK텔레콤 로고*

| 컨소시엄 | 정부 발표의 서비스 방향 |
| :--- | :--- |
| SK텔레콤 | 실행형 AI |
| 카카오 | 메신저 기반 예약·결제 AI |
| KT | <mark>공공·생활 서비스 통합 AI</mark> |

KT는 별도 앱보다 기존 서비스에 통합하는 방식을, 카카오는 카카오톡 대화 흐름을 택했어요. 세 곳 모두 연내 정식 서비스가 목표라 12월에는 국산 AI 서비스 세 개가 같은 시기에 출시됩니다.

## 앞으로 주목할 점

- 클로즈 베타 참여 방법과 일반 이용자 공개 시점
- 12월 정식 출시 때 무료 이용 범위
- 참여사 모델로 전달되는 개인정보 범위와 보안 기준 공개
- 2027년부터 정부 예산이 지원되는 운영비 규모
