Microsoft와 Meta가 직원들의 Claude 사용을 줄이고 있다고 미국 매체 The Information이 2026년 10월 6일 보도했어요. Microsoft는 사내 Anthropic 지출 예상치를 3분의 1 넘게 축소했고, Meta 사내에서 Claude Code를 쓰는 직원은 연초 약 6만 명에서 약 3만 명으로 줄었어요. 두 회사 모두 고객에게 Claude를 제공하는 일은 그대로 유지하고, 직원이 쓰는 도구만 자체 제품으로 전환하는 중입니다.

![Anthropic 로고](/assets/images/ai/meta-microsoft-cut-internal-claude/01-logo-anthropic.webp)
*Anthropic 로고*

## 보도 내용

The Information 원문은 유료이며, 이 내용은 이를 인용한 디지털투데이·Channel Insider·Yahoo Finance 보도에 근거합니다. 두 회사는 축소 사실을 공식 발표하지 않았고, Microsoft 대변인은 사내 AI 코딩 기본 모델을 OpenAI 모델로 변경했지만 엔지니어가 Claude를 선택할 수는 있다고 확인했어요.

| 구분 | Microsoft | Meta |
| :--- | :--- | :--- |
| 축소 대상 | 사내 Claude 지출 예상 | Claude Code 사용자 |
| 규모 | **3분의 1 이상 축소** | **약 6만 → 약 3만 명** |
| 전환 대상 | GitHub Copilot·OpenAI 모델 | MetaCode·Muse Code |
| 고객용 Claude | 제공 유지 | 해당 없음 |

## Microsoft, 기본 모델을 OpenAI로

![Microsoft 로고](/assets/images/ai/meta-microsoft-cut-internal-claude/02-logo-microsoft.webp)
*Microsoft 로고*

보도에 따르면 Microsoft는 2026년 초 사내 Claude 사용에 연간 최소 1조 4,000억 원(10억 달러)을 지출할 것으로 예상했다가, 이 예상치를 3분의 1 넘게 축소했어요. 6만 명이 넘는 Cloud and AI 조직에서는 대부분 직원의 월 AI 사용 한도를 약 1억 4,000만 원(10만 달러)에서 약 1,400만 원(1만 달러)으로 축소했어요.

Claude Code 구독을 줄이고 직원이 GitHub Copilot을 통해 모델을 사용하게 했는데, Copilot의 자동 모드는 질의 대부분을 OpenAI 모델에 전달해요. Microsoft는 OpenAI와의 관계 때문에 이 모델들에는 사용료를 따로 내지 않는다고 디지털투데이는 전했어요.

Microsoft 개발자 도구 사업을 이끄는 Jay Parikh는 8월 사내 메모에서 OpenAI 모델로 작업을 더 전환하면 *greater value from our token investment*(토큰 투자에서 더 큰 가치)를 얻는다고 썼다고 해요.

## Meta, MetaCode와 Muse Code로

![Meta 로고](/assets/images/ai/meta-microsoft-cut-internal-claude/03-logo-meta.webp)
*Meta 로고*

![메타 사내 코딩 도구별 사용 인원](/assets/images/ai/meta-microsoft-cut-internal-claude/04-chart.webp)
*메타 사내 코딩 도구별 사용 인원 — 출처: The Information 보도(디지털투데이 · Channel Insider 인용) 기반 자가 렌더*

Meta 사내 Claude Code 사용자는 2026년 초 약 6만 명에서 약 3만 명으로 50% 감소했어요. 디지털투데이는 감소의 주된 이유를 자체 코딩 도구 확대로, 봄 해고의 영향은 그보다 작았다고 전했어요.

- MetaCode: 사내 전용 코딩 도구, 사용자 3만 명 이상
- Muse Code: Meta 자체 모델 기반, Claude Code와 경쟁하도록 시험 중, 사용자 약 6,000명
- Claude Code 지출: 최근 28일 동안 약 1,470억 원(1억 500만 달러) 이상

Stocktwits 보도에 따르면 Meta는 Muse 에이전트를 만드는 동안 Claude를 쓰다가 출시 시점에 자체 모델로 전환했어요.

## 고객용 Claude는 그대로

Microsoft는 Microsoft Foundry로 Anthropic 모델을 계속 유료 제공하고 있고, 고객에게 제공하는 Copilot 기능에 적용되는 Anthropic 모델 사용료로만 연간 최소 2조 8,000억 원(20억 달러)을 낸다고 보도됐어요. 고객 쪽 지출이 증가해 Microsoft가 Anthropic에 내는 전체 금액은 연중 최고치와 비슷한 수준이라는 보도도 있어요.

GitHub Copilot 유료 요금제에서는 모델 선택 메뉴로 Claude 모델을 직접 선택할 수 있고, Azure 고객은 Microsoft Foundry로 Claude를 쓸 수 있어요.

## Anthropic에 미치는 영향

![사내 코딩 도구를 다른 모델로 옮기는 개념 컷](/assets/images/ai/meta-microsoft-cut-internal-claude/05-agy.webp)
*사내 코딩 도구를 다른 모델로 옮기는 개념 컷 — 출처: 개념 컷 · agy 자가 생성*

보도는 Anthropic의 상장 준비가 진행되는 시점에 나왔습니다. 9월 28일 유출된 Anthropic 상장 신고서 초안에는 2025년 매출 약 6조 4,000억 원(45억 9,000만 달러) 가운데 고객 두 곳이 각각 12%, 합쳐 4분의 1 가까이를 차지했다고 적혀 있다고 Reuters가 보도했어요. 두 고객의 이름은 공개되지 않았어요.

같은 초안은 주요 고객 상당수가 장기 계약 없이 사용하고 있어 지출을 축소하거나 중단할 수 있다는 위험도 적었다고 해요. 디지털투데이는 OpenAI와 Google이 더 저렴한 요금을 제시하고 있어 저렴한 대안을 찾는 기업이 늘고 있다고 짚었어요.

## 앞으로 볼 것

- Anthropic 상장 일정과 정식 신고서의 고객 집중도 수치
- Microsoft·Meta 공식 입장, 특히 Meta의 Claude Code 사용 정책
- GitHub Copilot 기본 모델 변경이 사내뿐 아니라 고객 제품에도 적용되는지
- Muse Code의 사내 시험이 외부 제품으로 이어지는지
