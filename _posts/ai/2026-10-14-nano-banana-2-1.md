Google이 2026년 10월 6일 이미지 생성·편집 모델 Nano Banana 2.1(gemini-nano-banana-2.1)을 정식 출시했습니다. Nano Banana 2(Gemini 3.1 Flash Image)의 후속으로, Gemini 3.6 Flash를 기반으로 만들었어요.

API 가격은 1K 해상도 이미지 한 장에 **약 47원(0.0336달러)**으로 Nano Banana 2의 절반입니다. Google 자체 평가에서는 전체 선호도를 포함한 텍스트→이미지 3개 항목과 편집 7개 항목 모두에서 Nano Banana 2와 상위 모델 Nano Banana Pro보다 높은 평가 점수를 기록했어요.

## 바뀐 점

![Nano Banana 2.1 모델 카드 텍스트→이미지 평가표](/assets/images/ai/nano-banana-2-1/02-capture-t2i.webp)
*Nano Banana 2.1 모델 카드 텍스트→이미지 평가표 — 출처: Google DeepMind*

Gemini API 변경 내역에 적힌 개선점은 다섯 가지예요.

- 시각적 품질과 프롬프트 준수도
- 여러 턴에 걸친 캐릭터 일관성
- 이미지 안의 텍스트 렌더링
- 1:4·4:1·1:8·8:1 와이드·파노라마 비율 추가
- 1K·2K·4K 해상도 출력

모델 카드의 평가는 사람이 두 이미지를 나란히 보고 고르는 방식으로 매긴 Elo 점수입니다. 전체 선호도에서 Nano Banana 2.1(사고 모드)은 1050점으로 Nano Banana 2의 990점, Nano Banana Pro의 935점보다 높았어요.

인포그래픽 사실성 항목에서는 점수 차이가 크게 나타났습니다. 자동 평가로 매긴 점수가 0.521로 Nano Banana 2(0.179)의 약 3배였고, Nano Banana Pro(0.265)의 약 2배였어요. 사고 모드를 비활성화하면 0.328로 감소해, 정보가 많은 이미지는 사고 모드 여부에 따라 평가 점수가 달라집니다.

## 편집과 캐릭터 일관성

![Nano Banana 2.1 모델 카드 편집 평가표](/assets/images/ai/nano-banana-2-1/03-capture.webp)
*Nano Banana 2.1 모델 카드 편집 평가표 — 출처: Google DeepMind*

편집 평가 7개 항목에서도 Nano Banana 2.1(사고 모드)이 모두 1위였습니다.

| 항목 | 2.1 (사고) | Nano Banana 2 |
| :--- | :--- | :--- |
| 여러 인물 일관성 | **1106** | 978 |
| 마스크·펜 편집 | **1049** | 965 |
| 여러 참조 이미지 편집 | **1066** | 988 |
| 일반 편집 | 1026 | 938 |

여러 인물 일관성은 한 장면에 여러 캐릭터가 나올 때 얼굴·옷이 바뀌지 않는지를 보는 항목이에요. 마스크·펜 편집은 이미지 위에 영역을 칠하거나 낙서해 그 부분만 고치는 기능입니다.

모든 수치는 Google이 직접 진행한 평가이고, 2026년 10월 14일 기준 외부 기관의 독립 평가는 나오지 않았습니다.

## 한글 렌더링, 공식 자료가 밝힌 범위

![Nano Banana 2.1 모델 카드 용도와 알려진 한계](/assets/images/ai/nano-banana-2-1/04-capture.webp)
*Nano Banana 2.1 모델 카드 용도와 알려진 한계 — 출처: Google DeepMind*

모델 카드는 적합한 용도로 포스터·도식의 선명한 텍스트 생성과 **여러 언어의 현지화 텍스트 렌더링**을 꼽았습니다. 평가 항목에도 다국어(i18n) 텍스트 렌더링이 들어 있어요.

다만 언어별 결과는 공개하지 않았습니다. 지원 언어 목록이 없고, DeepMind 모델 페이지의 다국어 예시는 힌디어·독일어·스페인어여서 한국어 품질을 판단할 공식 근거는 없어요.

[작은 글자]
1K 해상도에서는 작은 글자가 자주 흐려짐

[긴 글]
긴 문단이나 한 페이지 분량의 글은 렌더링 품질이 떨어짐

[위치 혼동]
왼쪽·오른쪽 같은 공간 배치를 가끔 혼동함

간판·포스터처럼 글자가 중요한 이미지는 2K 이상으로 만들고 글자 수를 줄이는 것이 모델 카드의 한계에 맞는 사용법이에요.

## 가격

![Gemini API 해상도별 이미지 1장 가격 비교 차트](/assets/images/ai/nano-banana-2-1/05-chart.webp)
*Gemini API 해상도별 이미지 1장 가격 비교 차트 — 출처: Gemini API 요금표 기반 자가 렌더*

이미지 출력 토큰 단가는 100만 토큰당 4만 2,000원(30달러)으로 Nano Banana 2의 8만 4,000원(60달러) 대비 절반입니다. 대신 같은 4K 이미지가 차지하는 토큰이 2,520개에서 3,780개로 증가해, 4K 한 장 가격은 211원에서 158원으로 25% 인하되는 데 그쳐요.

국내 일부 글은 4K 가격을 장당 약 106원(0.0756달러)으로 전했지만, Google 요금표의 2.1 가격은 약 158원(0.113달러)입니다.

| 항목 | 2.1 단가 | Nano Banana 2 |
| :--- | :--- | :--- |
| 입력 (100만 토큰) | 2,100원 | 700원 |
| 텍스트 출력 (100만 토큰) | 1만 500원 | 4,200원 |
| 이미지 출력 (100만 토큰) | <mark>4만 2,000원</mark> | 8만 4,000원 |

입력과 텍스트·사고 출력 단가는 오히려 Nano Banana 2보다 3배, 2.5배 비쌉니다. 긴 지시문이나 참조 이미지를 여러 장 입력하고 사고 모드로 생성하면 장당 가격 절감 폭이 줄어들어요. Batch로 실행하면 모든 항목의 요금이 절반이고, 두 모델 모두 API 무료 티어는 없습니다.

## 쓸 수 있는 곳과 국내 이용

모델 카드에 적힌 배포 채널은 Gemini 앱, Google AI Studio, Gemini API, Google 검색 AI 모드, Google Ads, Google Flow, Google Stitch 일곱 곳입니다. 기존 Nano Banana 2(gemini-3.1-flash-image)는 지원 중단이 예고됐고 종료일은 발표되지 않았어요.

![Nano Banana 2.1 이용 경로 다섯 가지 정리 카드](/assets/images/ai/nano-banana-2-1/06-items.webp)
*Nano Banana 2.1 이용 경로 다섯 가지 정리 카드 — 출처: Google DeepMind 모델 카드·Gemini API 문서 기반 자가 렌더*

개발자는 한국에서도 Google AI Studio와 유료 Gemini API로 바로 쓸 수 있습니다. Gemini 앱에는 순차 적용된다고만 알려졌고, 한국의 Gemini 앱에 Nano Banana 2.1이 적용됐는지 확인할 수 있는 공식 발표는 2026년 10월 14일 기준 없어요. Gemini 앱 출시 노트에도 10월 13일까지 2.1 항목이 없습니다.

## 앞으로 주목할 점

- Gemini 앱 출시 노트에 2.1 적용과 국가 범위가 공지되는지
- 외부 기관의 독립 평가에서 Google 자체 Elo 결과가 재현되는지
- 언어별 텍스트 렌더링 평가 결과 공개 여부
- gemini-3.1-flash-image 지원 종료일
