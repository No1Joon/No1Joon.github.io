DeepSeek이 10월 17일 V4.1-Flash를 업데이트한 **V4.1-Flash-1017**을 공개했어요
같은 날 API의 **deepseek-flash** 모델과 웹·앱이 이 버전으로 교체됐습니다

자체 검색 엔진의 Search·Fetch API도 공개했어요
Claude Code·Codex를 거친 검색 호출은 <mark>10월 말까지 무료</mark>입니다

![V4.1-Flash-1017이 만든 자금성 3D 장면 데모](/assets/images/ai/deepseek-v4-1-flash-1017/01-hero.webp)
*V4.1-Flash-1017이 만든 자금성 3D 장면 데모 — 출처: DeepSeek*

## 발표 내용

![DeepSeek 공식 벤치마크 표, 1017 버전과 이전 버전·경쟁 모델 비교](/assets/images/ai/deepseek-v4-1-flash-1017/02-photo.webp)
*DeepSeek 공식 벤치마크 표, 1017 버전과 이전 버전·경쟁 모델 비교 — 출처: DeepSeek*

DeepSeek은 1017 버전을 V4.1-Flash의 **소규모 업데이트**라고 소개했어요
추론·코딩·에이전트 점수를 높이고 작업 시간과 출력 길이를 줄였다는 설명입니다

- 가중치: Hugging Face·ModelScope 공개, **MIT 라이선스**
- 규모: 총 파라미터(매개변수) 763B
- 컨텍스트: 100만 토큰, 최대 출력 384K 토큰
- 입력: 텍스트와 이미지
- API: 기존 이름 deepseek-v4-flash 요청도 1017로 처리

예시로는 자금성 3D 모델링, 웹 레이싱 게임, 선사시대부터 현대까지 이어지는 3D 장면을 공개했어요

## 벤치마크 수치

DeepSeek 자체 측정에서 가장 큰 폭으로 상승한 항목은 **Terminal-Bench 4.0**입니다
31.2에서 42.3으로 <mark>11.1포인트</mark> 상승했어요!

| 벤치마크 | 이전 V4.1-Flash | 1017 |
| :--- | :--- | :--- |
| HLE(도구 없음) | 36.8 | 42.6 |
| Terminal-Bench 4.0 | 31.2 | <mark>42.3</mark> |
| DeepSWE v1.1 | 74.2 | **77.0** |
| ProgramBench | 20.3 | 29.1 |
| Automation-Bench | 54.8 | 60.5 |

표의 비교 대상은 Claude Opus 5와 GPT 5.6-Sol이에요
9월에 출시된 Claude Opus 5.5·Sonnet 5.5와 GPT-6 계열은 이 표에 없습니다

HLE·Terminal-Bench·ProgramBench는 같은 표에서도 Opus 5가 높아요
Terminal-Bench는 Claude Code 환경에서 잰 값이라고 각주에 적혀 있습니다

Artificial Analysis 같은 외부 평가 기관의 1017 버전 점수는 아직 나오지 않았어요

## 작업당 비용

![DeepSWE v1.1 정답률 대 작업당 평균 비용 차트](/assets/images/ai/deepseek-v4-1-flash-1017/03-photo.webp)
*DeepSWE v1.1 정답률 대 작업당 평균 비용 차트 — 출처: DeepSeek*

DeepSWE v1.1 정답률은 77.0%, 작업당 비용은 약 280원(0.2달러)으로 표시했어요

같은 차트에서 GPT-6.1 Sol max는 약 2,200원(1.6달러)에 72% 안팎이에요
Claude Opus 5 max는 1만 6천 원(12달러) 안팎에 약 74%로 표시돼 있습니다

차트 수치는 DeepSeek이 작성한 것이고, 원화는 눈금을 읽어 환산한 근삿값이에요
<mark>토큰 단가보다 출력이 짧아진 효과가 작업당 비용을 낮췄다는 것이 DeepSeek의 설명입니다</mark>

## 요금과 한국 업무 시간

![DeepSeek 로고](/assets/images/ai/deepseek-v4-1-flash-1017/04-deepseek-logo-color.webp)
*DeepSeek 로고*

deepseek-flash 요금은 시간대에 따라 두 배 차이가 나요
피크 시간은 UTC 기준 평일 01~04시와 06~10시입니다

한국 시간으로 바꾸면 <mark>평일 오전 10시~오후 1시, 오후 3시~7시</mark>예요!!
국내 업무 시간 대부분에 피크 요금이 적용됩니다

| 100만 토큰당 (원) | 피크 | 그 외 |
| :--- | :--- | :--- |
| 입력(캐시 적중) | 8.4 | 4.2 |
| 입력(캐시 미적중) | 420 | 210 |
| 출력 | **1,680** | 840 |

Claude Haiku 5.5 정가는 100만 토큰당 입력 140원, 출력 700원이에요
토큰 단가만 보면 DeepSeek 할인 시간 요금도 Haiku 5.5보다 높습니다

작업당 비용은 쓰는 토큰 수에 따라 달라서, 단가만으로 어느 쪽이 싸다고 단정할 수는 없어요

## 검색 API와 Claude Code 연결

![Claude Code를 DeepSeek API에 연결하는 환경변수 설정](/assets/images/ai/deepseek-v4-1-flash-1017/05-term.webp)
*Claude Code를 DeepSeek API에 연결하는 환경변수 설정 — 출처: DeepSeek API 문서 기반 자가 렌더*

**Search API**는 검색 결과 목록을 반환해요

**Fetch API**는 웹 페이지 하나를 Markdown 본문으로 반환합니다

둘 다 성공한 요청 1,000건당 1,050원(0.75달러)이에요

DeepSeek Harness·Claude Code·Codex가 서버 측 도구로 부르는 검색은 현재 무료예요
과금은 한국 시간 11월 1일 오전 1시부터 시작됩니다

Claude Code는 DeepSeek의 Anthropic 형식 주소로 연결해요
이때 Claude 모델 이름은 DeepSeek 모델로 바뀌어 처리됩니다

DeepSeek은 **mcp_servers**·**cache_control** 같은 필드를 무시한다고 밝혔어요
Claude Code 기능 중 일부는 그대로 동작하지 않을 수 있습니다

## 국내에서 쓸 때 확인할 점

![개인정보보호위원회 로고](/assets/images/ai/deepseek-v4-1-flash-1017/06-logo-pipc.webp)
*개인정보보호위원회 로고*

개인정보보호위원회는 2025년 4월 DeepSeek에 시정권고를 내렸어요
이용자 프롬프트가 동의 없이 ByteDance 계열사로 전송된 사실이 실태 점검에서 확인됐습니다

DeepSeek은 2025년 2월 15일 국내 앱 신규 다운로드 제공을 중단했어요
한국어 처리방침을 공개한 뒤 4월 28일 재개했습니다

같은 시기 외교부·국방부 등 정부 부처와 금융권은 업무망에서 DeepSeek 접속을 차단했습니다

API로 보내는 코드와 문서는 DeepSeek 서버에서 처리돼요
회사 코드나 고객 정보를 다룬다면 <u>사내 보안 규정부터</u> 확인해야 합니다

가중치를 다운로드해 직접 실행하면 외부 전송은 없어요
다만 763B는 1바이트 정밀도로 단순 계산해도 가중치만 <mark>약 763GB</mark>라 개인 PC로는 어렵습니다
