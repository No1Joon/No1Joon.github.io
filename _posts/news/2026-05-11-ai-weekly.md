- 사내 AI 에이전트 세션 사용량이 직전 3개월간 600%+ 증가
- 퇴직자에게 2026년 말까지 전액 기본급 지급하는 패키지 제공
- 1분기 실적 발표 직후 주가 24% 하락

### ⭐ Microsoft Semantic Kernel RCE 취약점 공개 — 프롬프트 한 줄로 코드 실행

![Microsoft Semantic Kernel 보안 취약점 시각화](/assets/images/news/2026-05-11-ai-weekly/semantic-kernel-rce.webp)

Microsoft 가 자사 AI 에이전트 프레임워크 Semantic Kernel 의 RCE 취약점 두 건(CVE-2026-26030, CVE-2026-25592) 을 패치 후 공개했다. 프롬프트 인젝션이 호스트 단 임의 코드 실행·파일 쓰기로 이어질 수 있다는 점이 핵심.

- Python SDK(`<1.39.4`) 의 In-Memory Vector Store 필터에서 `eval()` 사용 — 단일 프롬프트로 `calc.exe` 실행 시연
- .NET SDK(`<1.71.0`) 의 SessionsPythonPlugin `localFilePath` 경로 검증 미흡 → 임의 파일 쓰기 가능

📰 [Microsoft Security Blog](https://www.microsoft.com/en-us/security/blog/2026/05/07/prompts-become-shells-rce-vulnerabilities-ai-agent-frameworks/) · 05.07
🏷️ `취약점` `Semantic Kernel` `프롬프트 인젝션`

### ⭐ Mythos 가 일으킨 '사이버 히스테리' — 금융권 비상, 전문가는 회의적

Anthropic Mythos 의 취약점 발견 능력이 알려진 뒤 미 금융권이 비상 대응 모드에 들어갔다. 그러나 보안 전문가들은 "구형 모델로도 같은 분석이 가능했고, 진짜 병목은 패치 속도" 라며 위협 자체가 과장됐다고 평가.

- Fed 의장·재무장관이 주요 은행 CEO 와 별도 회의 — Anthropic 모델 리스크 논의
- AI 가 취약점 발견 속도를 키우는 가운데 기업 패치는 여전히 수일~수주 소요 → 노출 창 확대
