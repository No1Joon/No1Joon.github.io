## 🔬 모델·기술

### ⭐ Anthropic, Claude Opus 4.8 공개 — SWE-bench Verified 88.6%, 동적 워크플로

Anthropic 이 5월 28일 Claude Opus 4.8 을 공개했다. SWE-bench Verified 88.6%, 에이전틱 코딩 69.2%, Online-Mind2Web 84% 로 직전 4.7 과 GPT-5.5 를 모두 앞선다고 회사 측은 밝혔다.

- 동적 워크플로(Dynamic Workflows) — 수백 개 서브에이전트를 병렬 조정하는 신규 기능 도입
- 가격은 입력 $5 / 출력 $25(per 1M tok) 로 4.7 과 동일. fast mode 속도는 2.5배
- 코드 결함을 그대로 통과시키는 비율이 4.7 대비 약 1/4 수준이라는 평가

### ⭐ Verizon 2026 DBIR — 취약점 익스플로잇이 1위 침투 경로, 섀도우 AI 45% 로 3배

Verizon 의 2026 데이터 침해 조사 보고서(DBIR) 가 5월 공개된 후 분석 보도가 이어졌다. 침해의 31% 가 소프트웨어 취약점 익스플로잇에서 시작 — 19년 만에 처음으로 자격증명 도용을 추월했다.

- 공격자가 LLM 으로 익스플로잇을 가속, "방어 가능한 시간" 이 수 개월 → 수 시간으로 압축
- 회사 기기에서 AI 서비스에 접속한 사용자 중 67% 가 비(非)법인 계정 사용 — 섀도우 AI 가 45% 로 전년 대비 3배
- 에이전트가 점유한 서비스 계정 한 개의 침해는 곧 자율적 행위자의 침해로 확장된다는 경고

### ⭐ Claude Code·Gemini CLI·Copilot Agent, GitHub 댓글 통한 프롬프트 인젝션에 노출

Aonan Guan(존스홉킨스) 연구팀이 "Comment and Control" 로 명명한 크로스벤더 취약점 클래스를 공개했다. PR 제목·이슈 본문·댓글에 악성 지시문을 심어 코딩 에이전트의 자격증명·토큰을 CI/CD 환경에서 그대로 빼내는 구조.

- 영향 — Anthropic Claude Code Security Review, Google Gemini CLI Action, GitHub Copilot Agent

- 인덱스/문서 같은 수동 트리거가 아닌 `pull_request`·`issues` 이벤트로 자동 트리거된다는 점이 핵심
