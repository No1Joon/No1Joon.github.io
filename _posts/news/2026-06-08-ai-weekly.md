### ⭐ Alphabet, AI 인프라 자금 $80B 조달 — 버크셔가 $10B 인수

Alphabet 이 6월 1일 자기자본 $80B 증자 패키지를 공시. 클래스 A·C 주식과 의무전환우선주를 묶은 구성이고, 그중 $10B 는 Berkshire Hathaway 가 사모방식으로 인수.

- ATM 프로그램 $40B + 인수 공모 $30B + Berkshire 사모 $10B 의 3단 구조
- Berkshire 가 2025년 3분기 이래 쌓아 온 Alphabet 포지션 위에 추가 베팅
- 사용처는 AI 컴퓨트·글로벌 인프라 캡엑스로 명시

📰 [Bloomberg](https://www.bloomberg.com/news/articles/2026-06-01/alphabet-to-raise-80-billion-in-equity-capital-for-ai-spending) · 06.01

### ⭐ DeepSeek, 첫 외부 펀딩 $7.4B — Tencent · CATL 이 주도

중국 DeepSeek 가 50B 위안($7.4B) 규모 첫 펀딩 라운드를 마무리 단계로. 투자 후 기업가치 $52B~$59B 추정.

- Tencent 10B 위안($1.5B), CATL 5B 위안($740M), 창업자 Liang Wenfeng 본인이 20B 위안($3B)
- 중국 국가 AI 산업 투자기금, NetEase, JD.com 도 참여 협의 중
- 자국 자본 중심 — 미국 투자자 부재

## 🔬 모델·기술

### ⭐ Microsoft, 자체 추론 모델 MAI-Thinking-1 공개 — OpenAI 의존도 낮추기

Build 2026 에서 Microsoft AI 가 자체 학습 추론 모델 MAI-Thinking-1 과 코딩 특화 MAI-Code-1-Flash 를 공개. 두 모델 모두 외부 모델로부터의 distillation 없이 라이선스 데이터만으로 학습했다고 설명.

- MAI-Thinking-1 은 35B active params 의 Sparse MoE, 256K 컨텍스트
- SWE Bench Pro 코딩에서 Anthropic Claude Opus 4.6 (2월 출시) 수준이라고 주장
- MAI-Code-1-Flash 는 GitHub Copilot 의 VS Code 모델 피커에 단계적 롤아웃

📰 [CNBC](https://www.cnbc.com/2026/06/02/microsoft-unveils-new-ai-models-lessen-reliance-on-openai-lower-costs.html) · 06.02
🏷️ `Microsoft` `MAI-Thinking-1` `MAI-Code-1-Flash`

### ⭐ Microsoft, AI 에이전트 통제용 오픈소스 표준 ACS 발표

Microsoft 가 Agent Control Specification (ACS) 를 오픈소스로 공개. 에이전트가 할 수 있는 일·금지 행위·사람 승인이 필요한 시점·감사 로그 형식을 일관된 규약으로 정의.

- 엔터프라이즈 도입 병목인 "에이전트가 정말 시키는 대로만 동작하느냐" 문제를 정조준
- 환경별로 흩어진 권한 모델을 표준화하려는 시도
- 같은 Build 행사에서 모델·런타임·통제 표준을 동시에 던진 셈

## ⚖️ 규제·정책

### ⭐ EU 기술 주권 패키지 발표 — Chips Act 2.0 + Cloud and AI Development Act

EU 집행위가 6월 3일 반도체·클라우드·AI 공급망 자립을 목표로 하는 기술 주권 패키지를 공개. 입법 2건(Chips Act 2.0, CADA)과 비입법 2건(오픈소스 전략, 에너지·AI 디지털화 로드맵).

- 반도체 €120B, 데이터센터 €200B 가 2036년까지 필요하다고 추산
- EU 주권 기준을 못 맞춘 클라우드 사업자는 민감 정부 계약 입찰 차단
- 공급 위기 시 칩 생산 우선순위를 EU 가 강제할 비상권한 포함

📰 [Bloomberg](https://www.bloomberg.com/news/articles/2026-06-03/europe-unveils-sweeping-tech-sovereignty-plan-to-boost-chips-ai) · 06.03
🏷️ `EU` `Chips-Act-2.0` `기술-주권`

### ⭐ EU €20B AI 데이터센터 5곳 계획, 자금·일정 문제로 표류

- 기술 주권 패키지의 데이터센터 €200B 추산과 자가 충돌하는 모양새
- 칩·전력·부지 확보 모두에서 미국·중국 대비 출발 지연

### ⭐ Claude Code GitHub Action 권한 우회 — 공개 저장소 탈취 시나리오 공개

GMO Flatt Security 의 RyotaK 가 Anthropic 의 공식 Claude Code GitHub Action 에서 권한 검증 결함을 보고. `[bot]` 으로 끝나는 actor 를 무조건 신뢰하던 로직이 핵심.

- Prompt injection 과 결합 시 비인증 외부 공격자가 시크릿·OIDC 토큰 탈취 및 악성 코드 푸시 가능
- `anthropics/claude-code-action` 저장소 자체가 취약 워크플로를 쓰고 있어 공급망 전파 위험
- Anthropic 은 1월 보고 후 4일 내 코어 패치, v1.0.94 에서 정리. CVSS v4.0 7.8 평가, 버그바운티 지급
