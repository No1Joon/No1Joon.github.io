삼성전자가 One UI 9 정식 버전 배포를 2026년 9월 16일 국내에서 시작했습니다. 첫 대상은 갤럭시 S26·S26+·S26 울트라 3종이고, 나머지 기종은 순차 확대입니다.

7월에 갤럭시 Z 폴드8 울트라·폴드8·플립8과 함께 먼저 출시된 버전이 이제 기존 사용자에게 배포되는 단계인데, 기기별 배포 시점은 공식 발표와 지역별 공지가 서로 다르고 새 기능에는 이용 조건이 있습니다.

*One UI 9 국내 발표 키 비주얼, 마이 팬캠으로 공연 영상에서 인물을 추적하는 화면 — 출처: Samsung Newsroom Korea*

## 배포 경과

![One UI 9이 처음 실린 갤럭시 Z 폴드8 라인업 런치 키 비주얼](/assets/images/tech/one-ui-9-rollout/02-zfold8-debut.webp)
*One UI 9이 처음 실린 갤럭시 Z 폴드8 라인업 런치 키 비주얼 — 출처: Samsung Global Newsroom*

One UI 9은 Android 17을 기반으로 하는 버전이고, 개발은 2026년 5월 12일 갤럭시 S26 시리즈 베타 프로그램으로 공개됐습니다. 베타는 한국을 포함해 미국·영국·폴란드·독일·인도에서 진행됐고, 정식 버전이 처음 탑재된 기기는 7월 22일 출시된 갤럭시 Z 폴드8 울트라·폴드8·플립8이었습니다.

기존 기종으로 확대되는 시점이 9월 16일입니다. 삼성전자 뉴스룸은 같은 날 자료에서 갤럭시 S26·S26+·S26 울트라부터 시작한다고 밝혔고, 9to5Google은 약 4개월의 베타를 거친 일정이라고 정리했습니다. 직전 버전인 One UI 8.5의 정식 배포가 5월 6일이었으니 두 버전 사이 간격은 넉 달 남짓.

구형 기종 일정은 지역별로 다릅니다. 삼성전자 태국이 공지한 일정표에 따르면 갤럭시 S25 시리즈와 Z 폴드7·플립7이 9월 28일, 갤럭시 S23 FE가 10월인데, Android Authority는 이 날짜가 태국 기준이라 국가·통신사에 따라 달라질 수 있다고 덧붙였습니다.

| 시점 | 대상 | 상태 |
| :--- | :--- | :--- |
| 7월 22일 | Z 폴드8 3종 | 최초 탑재 |
| 9월 16일 | S26·S26+·S26 울트라 | <mark>국내 배포 시작</mark> |
| 9월 28일 | S25·Z 폴드7·플립7 | 태국 공지 기준 |
| 10월 | S23 FE | 태국 공지 기준 |
| 미정 | S24·S23·탭 S9 이상 | 순차 확대 |

## 지원 기기 범위

![One UI 9 공식 워드마크 플레이트](/assets/images/tech/one-ui-9-rollout/03-plate-oneui9.webp)
*One UI 9 공식 워드마크 플레이트 — 출처: Samsung Newsroom Korea*

삼성전자는 전체 지원 목록을 한 장으로 공개하지는 않았습니다. 다만 발표 자료의 프라이버시 알림 지원 기기 주석이 사실상 목록 역할을 하는데, 갤럭시 S26·S26 울트라·S25·S25 FE·S24·S24 FE·S23·S23 FE, Z 폴드8 울트라·폴드8·플립8·폴드7·플립7·폴드6·플립6·폴드5·플립5, 탭 S11 울트라·탭 S11·탭 S10 울트라·탭 S10 플러스·탭 S9 울트라·탭 S9 플러스·탭 S9가 적혀 있습니다.

| 계열 | 지원 기준선 |
| :--- | :--- |
| 갤럭시 S | **S23·S23 FE** 이상 |
| 폴더블 | **Z 폴드5·플립5** 이상 |
| 태블릿 | **탭 S9** 이상 |

SamMobile은 갤럭시 A·탭·F·M·XCover 계열까지 포함해 93개 이상 모델이 대상이라고 집계했습니다. 반대로 갤럭시 S22 시리즈, S21 FE, Z 폴드4, 구형 A 시리즈는 제외된 것으로 정리되는데, 이 부분은 삼성전자 공식 문서가 아니라 해외 매체 집계라 국내 모델 기준으로는 소프트웨어 업데이트 메뉴에서 직접 확인하는 편이 정확합니다.

## 새 기능

![메시지 대화에서 약속 정보를 인식해 일정 추가를 제안하는 나우 넛지 화면](/assets/images/tech/one-ui-9-rollout/04-nownudge.webp)
*메시지 대화에서 약속 정보를 인식해 일정 추가를 제안하는 나우 넛지 화면 — 출처: Samsung Global Newsroom*

이번 버전의 주요 기능은 **마이 팬캠**입니다. 촬영한 영상에서 지정한 인물을 자동으로 추적해 화면 중앙에 두고, 장면이 움직이면 구도를 다시 잡아 줍니다. 아이 공연이나 공연장 영상처럼 한 사람만 남기고 싶을 때 편집 없이 정리하는 용도.

**나우 브리프**에는 생성형·편집형 카드가 추가됐습니다. 건강·날씨·영상 항목으로 카드를 직접 만들어 일일 요약에 무엇이 표시될지 사용자가 정하는 방식입니다.

**나우 넛지**는 사용 맥락을 파악해 다음 동작을 제안하는데, 메시지로 약속을 잡는 중이면 대화창을 벗어나지 않고 예약 정보를 불러오거나 공유된 위치를 저장할 수 있습니다.

**보증 및 케어**는 기기 지원 항목을 설정 메뉴에 추가했습니다. 삼성 계정에 연결된 기기의 보증 범위 확인, 자체 진단 실행, 수리 견적 조회, 삼성 케어플러스 관리와 서비스 예약까지 설정 안에서 처리합니다.

나머지는 기존 갤럭시 AI를 개선한 기능입니다.

- **크리에이티브 스튜디오**: 다가오는 일정을 근거로 이미지 생성 아이디어를 먼저 제안
- **통역**: 스레드 뷰로 이전 대화를 확인하고, 대화 모드 번역과 갤럭시 버즈 재생 지연 단축
- **문서 스캔**: 휘어진 책 페이지나 모서리가 접힌 종이도 보정, 손가락 지우기 개선
- **음성 녹음**: 요약에 제목과 표를 넣어 훑어보기 쉬운 구조로 출력

## 보안과 개인정보

![삼성전자 워드마크](/assets/images/tech/one-ui-9-rollout/05-logo-samsung.webp)
*삼성전자 워드마크 — 출처: Samsung*

보안 쪽 변화는 세 가지입니다. **시큐리티 브리프**는 악성 앱, 출처가 불명확한 앱, 불필요한 권한 사용 같은 사안을 나우 브리프 안에 모아 주기적으로 보여 줍니다.

**프라이버시 알림**은 온디바이스 AI로 위험 신호를 판별합니다. 앱이 백그라운드에서 불필요하게 권한에 접근하려 하면 그 시도를 알려 주는데, 판단이 기기 안에서 끝나므로 권한 사용 내역이 서버로 나가지 않습니다.

**스캠 탐지**는 적용 국가가 늘어납니다. 삼성전자가 주석에 적은 대상은 일본·캐나다·인도여서 국내는 이번 확대의 직접 대상이 아닌데, 이미 One UI 8.0 이상에서 보이스피싱 의심 전화 알림이 기본 활성화로 제공되고 2026년 4월 기준 사용률이 약 84%입니다.

국내 보안 기능도 강화됐습니다. 삼성전자는 2026년 6월 One UI 9에 피싱 앱 설치를 차단할 뿐 아니라 이미 설치된 앱의 실행까지 차단하는 기능을 넣는다고 밝혔는데, 판단 근거는 경찰청 협력 데이터와 갤럭시 스토어 평판 데이터입니다. 방송통신위원회·한국인터넷진흥원과 운영하는 악성 메시지 차단은 2024년 9월 도입 이후 2026년 4월까지 약 4억 건.

## Android 17이 가져온 변화

![Android 워드마크](/assets/images/tech/one-ui-9-rollout/06-logo-android.webp)
*Android 워드마크 — 출처: Android*

One UI 9의 바탕인 Android 17에는 삼성전자 기능과 별개로 플랫폼 차원의 변화가 있습니다.

- **시스템 연락처 선택기**: 앱이 연락처 전체 읽기 권한을 요구하는 대신, 필요한 항목만 지정해 사용자가 고른 연락처만 넘기는 방식 (API 레벨 37 이상)
- **고급 보호 모드**: 특정 기능을 제한해 공격 표면을 줄이는 모드로, iOS 잠금 모드와 성격이 비슷
- **위성 직접 연결**: 이동통신망이 없는 곳에서의 위성 연결 지원 개선
- **UWB 거리 측정**: 여러 기준점의 신호 도달 시간으로 위치를 계산하는 Downlink-TDoA API 추가
- **화면 크기 대응**: 화면 크기가 다른 기기에서 앱이 적응하는 방식 개선

이 가운데 연락처 선택기와 고급 보호 모드는 앱이 대응해야 효과가 있으므로, 실제 체감 정도는 앱 업데이트 속도에 따라 달라집니다.

## 업데이트 전 확인할 점

![순차 배포되는 소프트웨어 업데이트 개념 컷](/assets/images/tech/one-ui-9-rollout/07-agy.webp)
*순차 배포되는 소프트웨어 업데이트 개념 컷 — 출처: 개념 컷 · agy 자가 생성*

기능마다 이용 조건이 있습니다. 삼성전자가 발표 자료 주석에 적은 전제만 모아도 다음과 같습니다.

| 기능 | 전제 조건 |
| :--- | :--- |
| 마이 팬캠 | **삼성 계정** 로그인, 추적 대상 없으면 미지원 |
| 나우 브리프·나우 넛지 | 삼성 계정, 국가·언어·모델별 차이 |
| 통역 | 언어 팩 다운로드 필요 |
| 보증 및 케어 | 수리 견적은 모델·지역별 차이 |
| 스캠 탐지 | <mark>일본·캐나다·인도</mark> 우선 |

체감 변화의 폭도 감안해야 합니다. SamMobile은 One UI 8.5를 쓰던 사용자라면 큰 차이를 느끼기 어렵고, 이번엔 개선에 집중한 버전이라 큰 개편은 갤럭시 S27과 함께 출시될 One UI 9.5 쪽일 수 있다고 봤습니다. 실제 확인된 UI 변경도 잠금 화면 미디어 플레이어의 파형 애니메이션, 밝기·음량 슬라이더 두께, 원형으로 바뀐 미디어 컨트롤 정도.

배포 초기인 만큼 안정성 문제 제보도 나옵니다. 삼성 멤버스 국내 게시판에는 업데이트 후 배터리 소모가 늘었다는 글과 PiP 영상 재생이 버벅인다는 글, 충전 애니메이션이 간헐적으로 표시되지 않는다는 글이 올라왔습니다.

반대로 컨트롤 패널 프레임 드롭이 사라졌다는 반응도 있어 기기·사용 패턴에 따라 반응이 다른 것으로 보이지만, 정식 배포 버전이라도 초기 빌드인 점은 감안하는 편이 안전합니다.
